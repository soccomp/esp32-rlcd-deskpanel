ESP32-S3-RLCD 桌面面板 · 操作使用说明

Waveshare ESP32-S3-RLCD-4.2 · 400×300 反射式单色屏 · 三页 UI（时间天气 / 吉他解压 / 摄像头）

一句话总览

本设备没有触摸屏，所有操作靠屏幕顶端 3 个实体键。中间那颗是硬复位键（PWR），按一下整机重启、回到首页；只有左右两颗侧键可编程。屏幕共有 3 个页面，左右键用来在页面间和页面内翻动。下面逐页讲解。

① 三个键分别是什么

面对屏幕、键在顶端，从左到右（已按你手上的实机核定）：左 BOOT 中 PWR 右 KEY。板上的丝印是 BOOT / PWR / KEY；实际 GPIO 为 左=GPIO0、右=GPIO18。固件把这两颗键映射成：左键＝下一页，右键＝上一页；在吉他页里左/右键分别负责切和弦与拨弦。

左键 · BOOT（GPIO0）
低电平有效，可编程
短按/长按 = 下一页（首页→吉他→摄像头→首页）
吉他页：短按 = 切换和弦（Cmaj7→Am7→Dm7→G7）
中键 · PWR（硬复位）
连 CHIP_PU，固件无法捕获
按一下整机重启，开机后停回首页。
相当于"回首页 / 救命键"。
右键 · KEY（GPIO18）
低电平有效，可编程
短按 = 上一页（摄像头→吉他→首页）
吉他页：短按 = 拨弦（扫弦+音效）；长按 = 切换和弦练习组
设备俯视示意（屏在板中央，三键在顶端边缘）。左键=下一页，右键=上一页。

② 三个页面是什么

页码名称内容
0首页 / 时间天气页翻页数字钟（时:分）、日期星期+法语短句、左下室内温湿度+今/明日天气、右上股票指数行情、右下摄像头缩略预览
1环境 / 吉他解压页左侧电吉他（拨弦+和弦+摇滚功德），右侧环境监测卡 + 办公室热闹雷达
2摄像头页320×240 全屏实时预览（由桌面 ESP32-CAM 经 USB 串口回传）
页面切换图：左键 = 下一页（0→1→2→0），右键 = 上一页（0→2→1→0）。

③ 怎么切到你要的页面

🏠 切到首页（时间天气页）

最简单：按中间的 PWR 键硬重启，开机默认停首页。
若当前在吉他页(1)：按一下左键（下一页）→ 回首页。
若当前在摄像头页(2)：按一下左键（下一页）→ 回首页。

🎸 切到吉他拨弦页（环境/趣味页）

从首页(0)：按一下左键（下一页）→ 进入吉他页。这是看到吉他页最直接的方式。
从摄像头页(2)：按一下右键（上一页）→ 进入吉他页。
吉他页（第1页）示意：左侧吉他 + 和弦横幅 + 摇滚功德；右侧环境监测卡 + 热闹雷达（扫描线每 2.2 秒转一圈）。

🎵 在吉他页怎么拨弦

吉他页里，右键 = 拨弦键，左键 = 切和弦。

在吉他页短按右键 → 触发一次扫弦：6 根琴弦依次振动、扬声器播出当前和弦琶音、「摇滚功德」+1。想连弹就连续短按。
在吉他页短按左键 → 切换到下一个和弦（Cmaj7→Am7→Dm7→G7 循环）；长按右键 → 在 OPEN / 7TH 两个和弦练习组之间切换。
要离开吉他页：按左键（下一页）→ 摄像头页；或按右键（上一页）→ 回首页。

📷 切到摄像头页

从首页(0)：按一下右键（上一页）→ 进入摄像头页。全屏实时预览，摄像头离线时显示"离线"提示。
从吉他页(1)：按一下左键（下一页）→ 进入摄像头页。

④ 必须知道的注意事项

✅ 会议日程页已移除。
本固件不再拉取/展示会议日程，设备上不存在会议页。若你不再需要 M1 上的会议后端（schedule-api 服务），可以自行停用，不影响设备其它功能（天气直连 Open-Meteo，行情/摄像头另有数据源）。

其它要点

  • 长按判定：按住约 0.6 秒以上算"长按"。吉他页里右键长按=切和弦组、短按=拨弦，靠时长区分。
  • 屏无背光：反射式屏幕靠环境光，暗处看不清是正常的，补点光即可。
  • 吉他页音效：需要扬声器功放使能（GPIO46 已拉高），连不连 Wi-Fi 都能响。
  • 进入下载模式：按住 BOOT 再按 PWR 重置，可进 ESP32 下载模式（烧录用）。注意：本说明里的"左键=BOOT(GPIO0)"正是这颗下载键。
