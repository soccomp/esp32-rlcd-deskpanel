ESP32-S3-RLCD 桌面面板 · 操作使用说明

Waveshare ESP32-S3-RLCD-4.2 · 400×300 反射式单色屏 · 三页 UI（时间天气 / 会议 / 吉他解压）

一句话总览

本设备没有触摸屏，所有操作靠屏幕顶端 3 个实体键。中间那颗是硬复位键（PWR），按一下整机重启、回到首页；只有左右两颗侧键可编程。屏幕共有 3 个页面，左右键用来在页面间和页面内翻动。下面逐页讲解。

① 三个键分别是什么

面对屏幕、键在顶端，从左到右（已按你手上的实机核定）：左 BOOT 中 PWR 右 KEY。板上的丝印是 BOOT / PWR / KEY；实际 GPIO 为 左=GPIO0、右=GPIO18。固件把这两颗键映射成：左键＝下一页/会议导航，右键＝上一页/吉他/离开会议。

左键 · BOOT（GPIO0）
低电平有效，可编程
首页：短按/长按都 = 下一页（去会议页）
会议页：短按 = 会议卡片下翻；长按 = 切换「全部 / 我的会议」
吉他页：短按 = 回首页
中键 · PWR（硬复位）
连 CHIP_PU，固件无法捕获
按一下整机重启，开机后停回首页。
相当于"回首页 / 救命键"。
右键 · KEY（GPIO18）
低电平有效，可编程
首页：短按 = 上一页（去吉他页）
吉他页：短按 = 拨弦（扫弦+音效）
会议页：短按 = 卡片上翻；长按 = 离开本页（回首页）
设备俯视示意（屏在板中央，三键在顶端边缘）。左键=下一页/会议，右键=上一页/吉他/离开。

② 三个页面是什么

页码名称内容
0首页 / 时间天气页翻页数字钟（时:分）、日期星期、左下室内温湿度+今/明日天气、右下「我的下一场会议」黑底白字卡
1会议日程页可翻页的会议卡片列表（每屏 3 张），顶部指示栏显示「全部会议 N · 第x/y页」或「我的会议 N · 第x/y页」
2环境 / 吉他解压页左侧电吉他（拨弦+和弦+摇滚功德），右侧环境监测卡 + 办公室热闹雷达
页面切换图：左键 = 下一页（顺时针 0→1→2→0），右键 = 上一页（首页直接跳到吉他页）。会议页内长按右键即可返回首页，不再需要硬重启。

③ 怎么切到你要的页面

🏠 切到首页（时间天气页）

最简单：按中间的 PWR 键硬重启，开机默认停首页。
若当前在吉他页(2)：按一下左键（下一页）→ 直接回首页。
若当前在会议页(1)：长按右键（≥0.6 秒） → 离开会议页，回到首页（无需硬重启）。

📅 切到会议页（全部会议）

从首页(0)：按一下左键（下一页）→ 进入会议页。
从吉他页(2)：按一下 左键（吉他→首页），再按一下左键（首页→会议）。
会议页（第1页）示意：顶部指示栏 + 每屏 3 张会议卡；带「我的」标记的卡片为反色黑底。长按右键即可退出本页。

⭐ 切到「我的会议」视图

「我的会议」不是独立页面，而是会议页的一种筛选状态。进入会议页后：

在会议页内长按左键（≥0.6 秒） → 在「全部会议」与「我的会议」之间切换。顶部指示栏文字会从「全部会议…」变成「我的会议…」，卡片只留下标了「我的」的会议（反色黑底）。再长按一次切回全部。
提示：会议数据来自后端/离线兜底；连上 Wi-Fi 后约 1 小时自动刷新一次，并且每次打开会议页都会自动拉取一次最新日程（无需手动刷新）。

🎸 切到吉他拨弦页（环境/趣味页）

从首页(0)：按一下右键（上一页）→ 进入吉他页。这是看到吉他页最直接的方式。
从会议页(1)：长按右键离开会议页回到首页，再按右键去吉他页；或直接从会议页长按右键离开后连续按两次右键。
吉他页（第2页）示意：左侧吉他 + 和弦横幅 + 摇滚功德；右侧环境监测卡 + 热闹雷达（扫描线每 2.2 秒转一圈）。

🎵 在吉他页怎么拨弦

吉他页里，右键 = 拨弦键（左键在此时负责"离开本页"，见下）。

在吉他页短按右键 → 触发一次扫弦：和弦横幅切换（Cmaj7→Am7→Dm7→G7 循环）、6 根琴弦依次振动、扬声器播出琶音、「摇滚功德」+1，并飘出 ROCK +1。想连弹就连续短按。
要离开吉他页：按左键（下一页）→ 回首页。（吉他页里右键只拨弦、不翻页。）

④ 必须知道的注意事项

✅ 会议页陷阱已修复：长按右键即可离开。
老固件里进入会议页后，左右键都被困在会议页内部（翻卡片/筛选/刷新），没有任何键能离开，只能硬重启。新固件改为：在会议页长按右键（≥0.6 秒）直接返回首页；短按右键仍是上翻卡片，短按/长按左键仍是下翻/筛选。手动刷新改为"打开会议页自动拉取一次"，无需再长按刷新。

其它要点

  • 长按判定：按住约 0.6 秒以上算"长按"。会议页里短按=翻页、长按=切换筛选/离开，靠这个时长区分。
  • 首页的「我的下一场会议」：黑底白字卡，自动从会议数据里挑出"你参加、且最近的一场"显示，并会在会议开始前 10 分钟响一声"滴滴"提醒（需连过 Wi-Fi 拉到数据）。它和会议页的「我的会议」筛选是两回事。
  • 屏无背光：反射式屏幕靠环境光，暗处看不清是正常的，补点光即可。
  • 吉他页音效：需要扬声器功放使能（GPIO46 已拉高），连不连 Wi-Fi 都能响。
  • 进入下载模式：按住 BOOT 再按 PWR 重置，可进 ESP32 下载模式（烧录用）。注意：本说明里的"左键=BOOT(GPIO0)"正是这颗下载键。
